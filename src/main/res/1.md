27. (8 pts) Retrieve all listings where location coordinates are within 50 miles of longitude -74.0060 and latitude 40.7128 (New York).
This question introduces a new concept which is not covered in class: geospatial queries in MongoDB. The goal is to find all listings where location.coordinates are within 50 miles of New York. You can verify the above-mentioned coordinates of New York here.
Hints and Assumptions:
● Since geospatial queries are new to this class, this is an opportunity to explore MongoDB documentation and learn how to work with coordinates. You'll need to use $geoWithin along with $centerSphere to calculate a circular region based on latitude and longitude. See documentation and examples for more help.
● Earth's radius is approximately 3960 miles, so the formula to convert miles to radians is: radius in radians = radius in miles / 3960
```
{
"address.location": {
"$geoWithin": {
"$centerSphere": [
[-74.0060, 40.7128],
50 / 3963.2
]
}
}
}
```
